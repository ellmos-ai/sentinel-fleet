# Canva UI Stylist & Enterprise Design Token Engine

## Purpose
Enforces state-of-the-art UI/UX patterns across SentinelFleet interfaces, including harmonious color palettes, accessible contrasts (WCAG AAA), smooth micro-animations, and fluid light/dark responsive layouts.

## Design Principles
1. **Light by Default:** Clean, high-contrast slate surfaces with Google Cloud accents.
2. **Harmonious Tokens:** 8pt grid, curved radii (8px–12px), subtle elevations (1px border + soft box-shadow).
3. **Stateful Feedback:** Visual confirmation badges, responsive pill tags, and animated transition states.
