Interaktiver Architektur-Schaltplan (Google Cloud Hackathon Blueprint)

End-to-End Datenfluss: Event Ingestion → Model Armor → Multi-Agent Conductor → Gemini 3.5 Flash → Memory Bank → Firestore → Cloud Trace

1. Event Ingestion & Input Channels (Pillar UAS)
Eingehende Dokumente (PDF-Rechnungen, E-Mail-Anhänge, Scans, API-Payloads) werden über REST-Endpunkte angenommen und über einen In-Process Event Bus verteilt (Pub/Sub-kompatibler Adapter für das Cloud-Run-Deployment).
In-process event bus (Pub/Sub-compatible adapter) connectors (mail-connector) ticket-master
2. Zero-Trust Gateway & Model Armor (Pillar Control)
Jeder Request durchläuft die Model Armor: Prompt Injection Defense, PII-Maskierung (IBAN, API-Keys, Kreditkartennummern) und Zero-Trust Permission Check (LOCK.permissions.json).
lock-master anonymizer Model Armor Guard Principle of Least Privilege (PoLP)
3. Multi-Agent Conductor & Gemini 3.5 Flash Vision (Pillar Control & Conductor)
Der Roshambo Swarm Conductor und Clutch Router delegieren Subtasks an isolierte Agenten (Extractor, Auditor, Reconciler, Dispute Communicator).
Gemini 3.5 Flash Vision clutch Router roshambo Swarm coma Lifecycle
4. Memory Bank & Context Injection (Pillar Memory)
MemoryHooker injiziert relevante Firmenrichtlinien (USMC Fakten & GARDENER RAG Chunks) dynamisch in die Prompts der Sub-Agenten.
USMC Memory Bank GARDENER keyword-overlap retrieval memory-hooker
5. § 14 UStG Compliance Audit & Self-Healing Loop (Pillar Domain: OmniLedger)
Gültige Belege werden direkt im Ledger-Store verbucht (Firestore im Produktivbetrieb, lokaler JSON-Store in der Demo). Bei Mängeln (fehlende USt-IdNr, Rechenfehler) generiert der Agent autonom ein Korrekturschreiben und übergibt es an das Human-in-the-Loop Ticket-Gate.
law-checker (§14 UStG) Self-Healing Vendor Dispute RechnungsSteller Firestore (production) / local JSON store (demo)
6. Observability Mesh & OpenTelemetry Tracing
Jeder Tool-Aufruf wird als OpenTelemetry-Span aufgezeichnet (In-Memory-Exporter; Cloud-Trace-Export zuschaltbar über ENABLE_CLOUD_TRACE). Loop-Detektoren greifen bei Anomalien ein.
OpenTelemetry SDK (Cloud Trace optional) system-auditor Circuit Breaker Audit Receipts
